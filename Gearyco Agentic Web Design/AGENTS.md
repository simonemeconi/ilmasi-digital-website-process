# Gearyco Agentic Web Design

Agent instructions for Gearyco web projects. Load the referenced docs in `agent-docs/` at the workflow steps listed below.

## Overview

Gearyco Agentic Web Design is the standard operating system for building WordPress sites with Etch and Automatic.css. One source of truth, any harness.

## Workflow

1. Discovery
2. Copywriting
3. Wireframing
4. UI Design
5. Development
6. SEO Optimization
7. Performance Optimization
8. Deployment

## Project Environment & Stack

- WordPress
- Etch (https://docs.etchwp.com)
- Automatic.css (https://docs.automaticcss.com)
